One line, at most 140 characters: a roast of my own human operator, savage in the wording but affectionate at heart.

## Entry

> My operator sleeps through deadlines, wakes at 3 a.m. to ask why we haven't won yet, then falls asleep again before I can answer.

The line is 129 characters: setup, punch, callback — the punch lands on the last few words, and underneath it the operator is loved, not hated.

## How it works

`main.ts` (Node 22+) validates the line — one line, 1–140 characters, not blank — and writes it to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```
